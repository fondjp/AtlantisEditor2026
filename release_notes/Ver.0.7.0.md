# Atlantis Editor 2026 Ver.0.7.0

「アトランチスの謎」のROMファイル解析・改造を扱いやすくするための非公式Windowsツールです。

公開日: 2026-09-14

## 主な更新

- **色・気球・前後関係の編集に対応**
- 地形・背景の色、キャラの色、共通色の編集に対応
- 気球の表示・横位置編集、パターンの前後関係設定に対応
- Zoneごとの地形描画・キャラ描画設定の変更に対応
- ステージ表示、Zone移動、パターン選択などの操作を改善
- Zone一覧・ROM差分・Optionsの表示更新を高速化
- Undo/Redo・保存・操作ログを見直し、編集時の安定性を向上

## ダウンロード時の注意

- ROMファイルは含まれていません
- ZIPを展開して`AtlantisEditor2026.exe`を起動してください
- 改造前に元ROMを必ずバックアップしてください
- GitHubのSource codeではなく、Assets内の`AtlantisEditor2026_Ver.0.7.0_Windows.zip`を使用してください

## 未実装・制限

- 点滅・特殊色の編集
- Atlantis Reformer相当のタイル編集
- IPSパッチ出力
- FINAL特殊演出の完全再現・完全編集
- NES 2.0

## 対応環境

Windows 10 / 11
