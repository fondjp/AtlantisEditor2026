# Atlantis Editor 2026 Ver.0.6.0

「アトランチスの謎」のROMファイル解析・改造を扱いやすくするための非公式Windowsツールです。

公開日: 2026-07-15

## 主な更新

- 大規模な軽量化・全面的な内部再設計
- 巨大化していたコードを役割ごとに分離し、重複した解析・表示更新を大幅に削減
- Undo／Redo、ドラッグ＆ドロップ、パターン選択、一覧更新などの動作を高速化
- 扉、宝箱／アイテム、特殊処理、最適化、保存処理の安全性を見直し、多数の不具合を修正
- ROM保存時のバックアップ、読み戻し確認、エラー報告・復旧機能を強化
- Ver.0.6.0以降のUI設定引継ぎに対応
- 一覧表示、右クリックメニュー、操作ログ、編集画面を整理
- タイトルデモで使用する扉の設定に対応
- 公開前の最終UI調整を行い、ROM未読み込み時の不要な表示を抑制
- Optionsの説明文とステージセレクト一覧の初期表示を調整

## ダウンロード時の注意

- ROMファイルは含まれていません
- ZIPを展開して`AtlantisEditor2026.exe`を起動してください
- 改造前に元ROMを必ずバックアップしてください
- GitHubのSource codeではなく、Assets内の`AtlantisEditor2026_Ver.0.6.0_Windows.zip`を使用してください
